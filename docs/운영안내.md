# BooKLove 모임 공간 — 운영 안내

모임 공간 주소: 사이트 주소 뒤에 `community/` (허브 화면 아래쪽 「서재 · 서평 · 나눔」 버튼으로도 들어갑니다)

- **서재**: 함께 읽은 책 목록. 책을 누르면 읽은 날짜, 그날의 기록, 멤버 서평(별점·한줄평·서평)이 나옵니다.
- **나눔**: 이름 없이 글과 댓글을 남기는 게시판. 글마다 「책갈피 23」 같은 임의의 별명이 붙습니다.
- **자료실**: 모든 회차 기록을 최신순으로 모아 둔 목록.
- **읽기**는 지금처럼 허브 암호로 들어온 분이면 누구나, **쓰기**는 「입장 코드」를 아는 멤버만 할 수 있습니다.

---

## 1. 지금 상태: 체험 모드

`community/config.js`의 `supabaseUrl`, `supabaseAnonKey`가 비어 있으면 **체험 모드**입니다.

- 아무 입장 코드나 넣어도 글이 써집니다.
- 쓴 글은 **그 기기의 브라우저에만** 저장되고 다른 멤버에게는 보이지 않습니다.
- 화면 위에 「체험 모드입니다」 안내가 뜹니다.

멤버들이 서로의 서평과 나눔을 보려면 아래 2~5단계로 **실제 모드**를 켜야 합니다. 비용은 무료 요금제로 충분합니다.

## 2. Supabase 무료 프로젝트 만들기 (목사님이 직접)

1. https://supabase.com 에 들어가 **Start your project** → 구글 계정 등으로 가입합니다.
2. **New project**를 누릅니다.
   - Name: `booklove` (아무 이름이나 괜찮습니다)
   - Database Password: 긴 비밀번호를 만들고 **따로 안전하게 보관**합니다. (사이트에는 절대 넣지 않습니다)
   - Region: **Northeast Asia (Seoul)**
   - 요금제: **Free**
3. 프로젝트가 만들어질 때까지 1~2분 기다립니다.

> 참고: 무료 프로젝트는 일주일 넘게 아무도 쓰지 않으면 잠시 멈춤(pause) 상태가 될 수 있습니다. 그러면 Supabase 화면에서 **Restore**를 누르면 다시 켜집니다.

## 3. 표 만들기 (schema.sql 붙여넣기)

1. 왼쪽 메뉴 **SQL Editor** → **New query**.
2. 저장소의 `supabase/schema.sql` 파일 내용을 **전부** 복사해 붙여넣고 **Run**을 누릅니다.
3. 아래쪽에 `Success`가 나오면 끝입니다. (여러 번 실행해도 괜찮습니다)

## 4. 입장 코드 정하기

1. SQL Editor에서 새 쿼리를 열고 아래 한 줄을 붙여넣습니다. 따옴표 안을 원하는 코드로 바꿉니다. (6자 이상, 모임에서 말로 전하기 쉬운 것)

   ```sql
   select public.set_member_code('여기에-입장-코드');
   ```

2. **Run** → `member code updated`가 나오면 됩니다.
3. 데이터베이스에는 코드가 아니라 **암호화된 값(해시)만** 저장됩니다. 코드를 잊으면 같은 방법으로 새 코드를 정하면 됩니다.
4. 코드를 바꾸고 싶을 때(예: 학기가 바뀔 때)도 같은 줄을 새 코드로 다시 실행합니다.

> 입장 코드는 사이트 파일 어디에도 적지 않습니다. 모임 자리에서 직접 알려 주세요.

## 5. config.js 채우기

1. Supabase 왼쪽 아래 **Project Settings → API** (또는 **Data API**)로 갑니다.
2. 두 값을 복사합니다.
   - **Project URL** (예: `https://abcdxyz.supabase.co`)
   - **anon public** 키 (`eyJ...`로 시작하는 긴 글자)
3. `community/config.js`를 열어 이렇게 채웁니다.

   ```js
   supabaseUrl: 'https://abcdxyz.supabase.co',
   supabaseAnonKey: 'eyJ...',
   ```

4. 저장 → 커밋 → GitHub에 올리면 실제 모드가 됩니다. 화면 위 「체험 모드」 안내가 사라지면 성공입니다.

> ⚠ **service_role** 키는 절대 넣지 마세요. 그 키는 모든 권한을 가진 열쇠입니다. config.js에는 **anon public** 키만 넣습니다.

## 6. 지금 읽는 책 · 다음 모임 바꾸기

`community/config.js`의 `currentBook` 부분만 고치면 됩니다.

```js
currentBook: {
  slug: 'waste',                 // 책 폴더 이름
  note: '수요 오전 모임',
  nextMeeting: '10월 22일 (수) 오전 10시',
  place: '교육관 2층',
  example: false                 // true면 「예시」 표시가 붙습니다
}
```

지금 들어 있는 날짜·장소는 **예시**입니다. 실제 값으로 바꾸고 `example: false`로 해 주세요.

## 7. 새 책·새 회차가 생겼을 때

책 폴더나 회차 폴더를 추가해 커밋한 뒤, 저장소 폴더에서 한 번 실행합니다.

```bash
python3 tools/build_catalog.py
```

서재와 자료실 목록(`community/catalog.js`)이 새로 만들어집니다. 커밋된 폴더만 목록에 들어갑니다.

## 8. 글 관리 (숨기기)

부적절한 글이 올라오면:

1. Supabase → **Table Editor** → `reviews` / `posts` / `comments` 중 해당 표.
2. 그 줄의 `hidden` 칸을 **true**로 바꾸고 저장합니다.
3. 사이트에서 바로 사라집니다. (글을 숨기면 그 글의 댓글도 함께 숨겨집니다)

완전히 지우려면 그 줄을 삭제하면 됩니다.

## 9. 알아 두실 점

- **이름·연락처는 저장하지 않습니다.** 별명은 글마다 무작위로 붙습니다.
- 글쓰기 남용을 막기 위해 같은 인터넷에서 10분에 20번, 하루 100번까지만 쓸 수 있고, 틀린 코드는 한 시간에 10번까지만 받아 줍니다. 교회 와이파이 하나로 여러 분이 함께 쓰셔도 보통은 넉넉합니다.
- 허브 암호는 화면을 가리는 장치입니다. 실제 모드에서는 anon 키를 아는 사람이면 숨기지 않은 서평과 나눔을 **읽을 수는** 있습니다(쓰기는 코드 없이는 불가). 그래서 나눔에는 실명이나 다른 분의 개인 사정을 적지 않도록 안내해 주세요.
